Local-first RAG assistant / Portfolio Q&A

A local RAG assistant that answers recruiter questions from a curated portfolio knowledge base.

This project adapts a Google and MongoDB local RAG workshop into a portfolio-focused AI assistant. It ingests structured resume and project facts, retrieves relevant context with MongoDB Vector Search, and generates grounded answers through a local Ollama-hosted LLM.

System design

A recruiter-facing showcase for a private local RAG system.

01

Curated portfolio data

Resume-safe facts live in data/portfolio_docs.json, not in private folders or certificates.

02

Local embeddings

voyage-4-nano embeddings are generated locally through SentenceTransformers.

03

MongoDB Vector Search

MongoDB Local Atlas stores chunks and retrieves the most relevant portfolio context.

04

Ollama Gemma answer

A local Gemma model generates a grounded answer for the Streamlit chat UI.

Project value for reviewers
